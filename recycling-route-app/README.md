# ReRoute Collect

ReRoute Collect is a 3-page front-end web app for planning, approving, and completing recyclable glass bottle and cullet collection routes.

## Pages

- `route-plan.html` – submit route plans with dynamic collection points.
- `approval-dashboard.html` – review plans, view details, approve or reject.
- `collection-completion.html` – record actual collection completion for approved routes.

## Tech

- HTML
- CSS
- Vanilla JavaScript
- `localStorage` for persistence

## Run

Open `index.html` in any modern browser and navigate through the app.

## Storage Keys

- `reroute_route_plans`
- `reroute_completions`
